whatIs: >
  A Code Consultant provides expert interpretation and compliance strategy for
  the building, fire, accessibility, and energy codes that govern a project,
  especially where a design doesn't fit a straightforward prescriptive code
  path. Where a Permit Expediter manages the process of getting a permit
  application through a jurisdiction's review (the paperwork and
  relationships), a Code Consultant solves the underlying technical problem:
  researching which code edition and amendments apply, identifying where a
  design conflicts with code, and developing a performance-based or
  alternative-means-of-compliance strategy when strict prescriptive compliance
  isn't feasible. This work is common on complex, high-rise, healthcare, or
  historic-building projects where code conflicts are frequent and expensive
  to get wrong.
whatTheyDo:
  - Research which code edition, amendments, and local modifications apply to a specific project and jurisdiction
  - Review architectural and MEP drawings to identify code compliance issues before permit submission
  - Develop alternative-means-of-compliance or performance-based design strategies where prescriptive code can't be met
  - Prepare and present code variance or alternative-compliance requests to local building and fire officials
  - Advise project teams on egress, fire-rated construction, and accessibility code requirements
  - Perform code-compliance due diligence on existing buildings being considered for renovation or change of use
