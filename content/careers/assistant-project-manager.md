whatIs: >
  An Assistant Project Manager (APM) supports a Project Manager with more
  ownership than a Project Engineer typically holds, managing specific
  scopes of the budget, subcontracts, or schedule directly rather than
  mainly handling documentation and coordination. It's usually the step
  right before running a project independently as a full Project Manager.
  No license is legally required for this role.
whatTheyDo:
  - Manage the budget and subcontract compliance for assigned scopes of a project
  - Negotiate and process change orders for the portions of the project under their ownership
  - Track schedule progress for assigned scopes and flag risks to the Project Manager
  - Review and approve subcontractor pay applications for their assigned scopes
  - Lead specific coordination meetings independently rather than only supporting the PM's meetings
  - Take over full project responsibilities when the Project Manager is unavailable
