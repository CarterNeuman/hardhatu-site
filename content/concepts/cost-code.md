id: concept-cost-code
title: Cost Code
tier: free
category: Project Process & Lifecycle
definition: >
  A standardized numbering system that breaks a project's budget into granular
  categories by task and trade, cast-in-place concrete, drywall, electrical
  rough-in, and so on, used internally to track cost against budget at a much
  finer level than the project's single headline contract price.
whyItMatters: >
  Without cost codes, a project's budget is just one number, and there's no way to
  know whether concrete specifically is running over while electrical is running
  under. Cost codes make a budget granular enough to actually manage day to day,
  not just judge from the outside once the project is already finished.
example: >
  A $2 million renovation budget gets broken into cost codes like 03-300
  (cast-in-place concrete) and 09-900 (painting), so the project team can track
  exactly how each trade's actual spending compares to what was budgeted for it,
  rather than only watching the project's total.
careerAngle: >
  A [[career-cost-engineer|Cost Engineer]] builds and maintains the cost code
  structure, assigning every committed and actual cost to the right code so the
  budget stays trackable at a granular level throughout construction. A
  [[career-project-manager|Project Manager]] reviews cost code reports regularly
  to catch one specific trade running over before it threatens the whole
  project's margin.
whatGoesWrong: >
  A project team codes costs loosely or inconsistently, lumping several trades'
  costs under one generic code to save time entering data. By the time anyone
  notices the project is losing money, the cost code reports are too vague to
  show which specific trade or task actually caused it, and there's no way to
  fix the problem without reconstructing months of cost history from scratch.
