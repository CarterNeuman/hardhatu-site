id: concept-building-code
title: Building Code
tier: free
category: Safety & Regulatory Compliance
definition: >
  The set of legally adopted construction standards, typically based on a model code
  like the International Building Code (IBC), amended locally, that a building's design
  and construction must meet, covering everything from structural loads to fire
  separation to accessibility. The baseline every [[concept-plan-review|plan review]] and
  [[concept-special-inspection|special inspection]] checks work against.
whyItMatters: >
  Building code isn't one uniform national standard: it's a model code adopted and
  amended by each local jurisdiction, so the specific requirements a project has to meet
  can vary meaningfully by location even for an otherwise identical building. Knowing
  which code edition and local amendments actually apply matters as much as knowing the
  general requirements.
example: >
  A design that would satisfy the base International Building Code's fire-rating
  requirements still has to account for a stricter local amendment in that particular
  jurisdiction, since the adopted local code, not just the model code on its own,
  governs what's actually required.
careerAngle: >
  A [[career-quality-control-manager|Quality Control Manager]] inspects completed work
  against code requirements as part of routine quality control, catching gaps before
  work gets covered up. A [[career-project-engineer|Project Engineer]] researches
  specific code requirements the project manager or field team needs answered, since
  code questions come up constantly during construction.
whatGoesWrong: >
  A design team applies the base model code's requirements without checking for a
  stricter local amendment specific to that jurisdiction. The plan review catches the gap
  and requires a design revision, a delay that checking the actual adopted local code up
  front would have avoided.
