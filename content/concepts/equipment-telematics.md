---
id: concept-equipment-telematics
title: Equipment Telematics
tier: free
category: Technology, Data & Sustainability
definition: >
  GPS and onboard-sensor data streamed from heavy equipment, covering
  location, engine     hours, fuel consumption, idle time, and diagnostic
  fault codes, feeding a fleet-management     dashboard so an equipment
  manager can track utilization and maintenance needs across an     entire
  fleet remotely.
whyItMatters: >
  A piece of equipment sitting idle on a site costs the same in ownership or
  lease payments     as one running productively, so telematics data showing
  which machines are actually being     used, and which are burning fuel while
  idle, turns a guess about fleet utilization into an     actual number an
  equipment manager can act on.
example: >
  An equipment manager reviewing a fleet dashboard notices an excavator has
  logged 40% idle     time over the past month on a site that reported it as
  fully utilized, and reassigns the     machine to a different project rather
  than renting an additional unit.
careerAngle: >
  An [[career-operations-manager|Operations Manager]] uses telematics data to
  schedule     preventive maintenance by actual engine hours rather than
  guessing, and to decide whether an     underused machine should move to a
  different site instead of sitting idle.
whatGoesWrong: >
  A fleet manager assumes telematics data alone proves a machine is being used
  efficiently     just because it's moving, when extended idle time with the
  engine running still burns fuel     and accumulates engine hours without
  doing any productive work.
