title: Benchmark (Survey Monument)
tier: free
category: Project Process & Lifecycle
definition: >
  A permanent, precisely surveyed physical point, often a metal disk set in
  concrete or a marked feature, used throughout a project as the fixed
  reference for all elevation and location measurements, so every trade's
  layout ties back to the same known point.
whyItMatters: >
  If a benchmark is disturbed or destroyed partway through a project, without it
  having been properly referenced to a backup point beforehand, every
  subsequent elevation and layout measurement loses its tie to a known,
  verified reference, a problem that can be expensive and slow to recover
  from.
example: >
  A site's primary benchmark, set by the surveyor before earthwork begins, is
  used throughout the project as the fixed elevation reference every trade
  ties its own layout back to, from grading to finish floor elevations to
  rooftop equipment heights.
careerAngle: >
  The [[career-surveyor|Surveyor]] establishes and protects the project's
  benchmarks before work begins, and the [[career-civil-engineer|Civil
  Engineer]] relies on them as the fixed reference for every elevation
  calculation on the project.
whatGoesWrong: >
  A benchmark gets knocked over by equipment mid-project with no backup
  reference point established beforehand, and the project has to bring in a
  surveyor to reestablish a verified elevation reference before any further
  layout work relying on it can be trusted.
relatedIds:
