title: Wind Load & Hurricane Code Requirements
tier: free
category: Safety & Regulatory Compliance
definition: >
  Building code provisions, based on regional wind speed maps, requiring
  structures in high-wind areas to be designed for specific wind loads, with
  coastal hurricane-prone regions, Florida's High-Velocity Hurricane Zone among the
  strictest, imposing additional requirements like impact-resistant glazing or
  approved storm shutters on every opening.
whyItMatters: >
  In a high-velocity hurricane zone, the requirement generally applies to every
  opening on the building, not just the ones facing the most exposed direction, so
  a design that treats only the ocean-facing windows as needing impact protection
  is missing the actual scope of the code.
example: >
  A coastal condo renovation replaces windows on every side of the building with
  impact-rated glazing, not just the ocean-facing units, since the local
  hurricane-zone code doesn't limit the requirement to whichever side faces the
  water.
careerAngle: >
  A [[career-structural-engineer|Structural Engineer]] designs to the applicable
  wind load, while a [[career-glazier|Glazier]] installs the impact-rated glazing
  systems the code requires in hurricane-prone zones.
whatGoesWrong: >
  A coastal renovation installs standard, non-impact-rated windows to save cost,
  assuming the requirement only applies to the most exposed side of the building.
  The project fails inspection under the local hurricane-zone code, and the
  homeowner's insurer separately refuses to write a policy without fully
  code-compliant glazing.
