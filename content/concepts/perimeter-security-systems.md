id: concept-perimeter-security-systems
title: Perimeter Security Systems
tier: free
category: Materials & Systems
csiDivision: "28, Electronic Safety & Security"
definition: >
  Detection systems monitoring a site's outer boundary, fence-mounted
  vibration or break sensors, buried cable detection, and perimeter cameras
  with analytics, used on high-security sites to detect an intrusion before it
  reaches the building itself.
whyItMatters: >
  Perimeter detection is most effective when it's tuned to the site's actual
  terrain and fencing, since an oversensitive system set up without that
  tuning generates so many false alarms from wind, animals, or vegetation that
  security staff start ignoring it.
example: >
  A contractor installing fence-mounted perimeter detection at a utility
  substation works with the security integrator to tune sensor sensitivity to
  the site's specific fence type and local wildlife activity before final
  commissioning.
careerAngle: >
  A specialty security subcontractor installs and tunes the system, while the
  [[career-safety-manager|Safety Manager]] or site security team defines the
  required detection zones.
whatGoesWrong: >
  A perimeter detection system is commissioned at factory-default sensitivity
  without site-specific tuning, and nuisance alarms from wind-blown debris
  become frequent enough that the security team starts disabling zones rather
  than fixing the tuning.
relatedIds:
  - career-safety-manager
