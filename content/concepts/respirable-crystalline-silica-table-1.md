id: concept-respirable-crystalline-silica-table-1
title: Respirable Crystalline Silica Table 1
tier: free
category: Safety & Regulatory Compliance
definition: >
  A specific table in OSHA's construction silica standard listing common tasks,
  like using a handheld grinder or a walk-behind saw, alongside the required
  dust control method and respirator use for each; an employer that follows
  Table 1 exactly for a listed task is not required to separately measure that
  task's silica exposure.
whyItMatters: >
  Table 1 offers a real shortcut: an employer who sets up the specified water or
  ventilation control and follows every Table 1 requirement for a task skips
  the cost and complexity of formal exposure monitoring for that task, which
  is often the more practical path for most contractors.
example: >
  A mason cutting concrete block with a handheld power saw uses an integrated
  water delivery system exactly as Table 1 specifies for that tool and task,
  letting the employer skip separate air monitoring for that specific
  operation.
careerAngle: >
  Superintendents should check whether a task matches a Table 1 listing exactly
  before assuming the exposure-monitoring shortcut applies, since deviating
  even slightly from the table's specified control method forfeits that
  shortcut.
whatGoesWrong: >
  Contractors sometimes assume using any dust control method satisfies the
  silica standard, when Table 1's exposure-monitoring exemption only applies
  if the employer follows that task's listed control method exactly as
  written, not an equivalent substitute.
