title: AutoCAD

category: "Design & BIM"
whatItIs: >
  Autodesk's general-purpose drafting software for precise 2D and 3D
  drawings, older and more general-purpose than Revit's building-specific
  parametric modeling.
whatItDoes: >
  AutoCAD focuses on precision drafting and documentation, producing 2D
  plans, details, and sheet sets along with some 3D geometry. Unlike
  Revit, where every element is a real parametric object tied to the
  rest of the model, AutoCAD's drawings are closer to traditional
  line-by-line drafting, which is exactly why it still gets used for
  work that doesn't need a full building information model. Industry
  specific toolsets add features for architecture, mechanical,
  electrical, and civil work on top of the core drafting engine.
keyFeatures:
  - Precision 2D drafting and documentation tools for plans, details,
    and sheet sets
  - 3D modeling with solids, surfaces, and mesh objects beyond flat line
    drawings
  - Industry-specific toolsets for architecture, mechanical, electrical,
    and civil work
  - Cloud and mobile versions for viewing and light editing away from a
    desktop
commonUses:
  - A CAD technician drafts detailed 2D construction documents and sheet
    sets for a project that doesn't need a full building information
    model
  - A civil engineer uses AutoCAD's civil-specific toolset to draft
    grading and utility plans
