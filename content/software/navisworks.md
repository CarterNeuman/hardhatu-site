tier: premium
category: "Design & BIM"
whatItIs: >
  Autodesk's model-review software, where the separate 3D models
  different trades build, often in Revit, get combined into one federated
  model and checked against each other.
whatItDoes: >
  Navisworks aggregates models from Revit, AutoCAD, and other design
  tools into a single combined model without requiring every trade to
  design inside the same platform. Its clash detection engine compares
  every discipline's geometry against every other discipline's and flags
  where two systems physically occupy the same space, catching a conflict
  on screen months before it would otherwise surface as a real problem in
  the field. A separate 4D mode links model elements to the project
  schedule so a team can watch the building go up in simulation before it
  goes up for real.
keyFeatures:
  - Model aggregation, combining models from Revit, AutoCAD, and other
    design tools into one federated model
  - Automated clash detection that flags where two trades' systems
    physically occupy the same space
  - 4D scheduling simulation, linking model elements to a project
    schedule to visualize the sequence of construction over time
  - Quantity takeoff tools that pull material counts directly from the
    combined model
commonUses:
  - A BIM/VDC Specialist runs a clash detection pass combining the
    structural, mechanical, and electrical models and finds a ductwork
    run cutting through a structural beam months before that beam is ever
    fabricated
  - A project team runs a 4D simulation of the erection sequence to
    confirm crane access won't be blocked by an earlier phase of the work
