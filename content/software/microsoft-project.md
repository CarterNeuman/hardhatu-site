whatItIs: >
  Microsoft's project scheduling tool, a smaller-scale and more widely
  available alternative to enterprise scheduling software like Primavera
  P6.
whatItDoes: >
  Microsoft Project builds a schedule around a Gantt chart view with
  critical path highlighting built in, letting a scheduler assign
  resources and track workload across a project's team. Lighter cloud
  based plans handle basic task tracking, while a desktop client and
  higher tiers add deeper scheduling control and portfolio-level
  reporting across multiple projects at once.
keyFeatures:
  - Gantt chart scheduling with critical path highlighting built into
    the standard view
  - Resource assignment and workload tracking across a project's team
  - Cloud-based plans for lighter task tracking, with a desktop client
    available for deeper scheduling control
  - Portfolio-level reporting across multiple projects at the higher
    subscription tiers
commonUses:
  - A project manager on a small to mid-size project builds a Gantt
    chart schedule and tracks the critical path without needing
    enterprise-level scheduling software
  - A scheduler on a smaller contractor uses Microsoft Project instead
    of Primavera P6 because the project's scale doesn't justify the
    added cost and complexity
