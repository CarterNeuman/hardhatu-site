whatItIs: >
  Structural analysis and design software, used by structural
  engineers to model a building's structural frame and check whether
  every beam, column, and connection can actually carry its loads.
whatItDoes: >
  RISA's products (RISA-3D for general structural analysis, plus
  companion tools like RISAFloor and RISAFoundation) let a structural
  engineer build a model of a building's frame, apply the loads it has
  to carry (gravity, wind, seismic), and run the analysis that checks
  every member against the relevant building code and material design
  standard. Instead of hand-calculating each beam and column, the
  engineer gets a code-check result across the whole structure at
  once, and the model updates automatically when a design changes, so
  a resized beam or an added column gets re-checked rather than
  requiring every calculation to be redone from scratch.
keyFeatures:
  - 3D structural modeling of a building's full frame (RISA-3D)
  - Automated load application (gravity, wind, seismic) and code
    checking against relevant building and material standards
  - Companion modules for floor systems (RISAFloor) and foundation
    design (RISAFoundation)
  - Automatic re-analysis when a design changes, instead of requiring
    every calculation to be redone by hand
commonUses:
  - A structural engineer models a building's steel frame and gets an
    automatic code check on every beam and column against the
    governing design standard
  - An engineer resizes a single overloaded beam and the model
    automatically re-checks every connected member rather than
    requiring a full manual recalculation
