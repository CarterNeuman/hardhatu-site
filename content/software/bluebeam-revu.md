whatItIs: >
  Nemetschek's PDF markup and measurement tool that has become the
  standard way construction teams review drawings, redline plans, and
  run digital takeoffs, on desktop, in a browser, or from a phone on
  the jobsite.
whatItDoes: >
  Revu turns a static PDF drawing set into something a whole project team
  can actually work inside. A reviewer marks up a sheet with text notes,
  shapes, or freehand annotations calibrated to the drawing's real scale,
  so a measurement taken on screen matches the real building. Its Studio
  Sessions feature lets multiple people open the same drawing set at once
  and see each other's markups appear live, instead of emailing separate
  marked-up copies back and forth and reconciling them by hand afterward.
keyFeatures:
  - PDF markup and redlining with text, shapes, stamps, and freehand tools
    calibrated to a drawing's actual scale
  - Measurement tools for length, area, volume, and count, used for
    takeoffs and quantity checks directly on the digital plan set
  - Studio Sessions, letting multiple reviewers mark up the same drawing
    set at the same time and see each other's changes appear live
  - Version comparison that shows exactly what changed between two
    revisions of the same sheet
commonUses:
  - A project engineer marks up a dimension question directly on a
    submittal drawing and shares it through a Studio Session instead of
    describing the location in a separate email
  - A quality control manager compares a newly issued drawing revision
    against the previous version to see exactly what changed before it
    reaches the field
