whatItIs: >
  Autodesk's building information modeling software, where architects,
  structural engineers, and MEP engineers build one shared 3D model of a
  project instead of drafting separate flat drawings.
whatItDoes: >
  Revit is parametric, meaning every wall, door, and beam in the model is
  a real object with real properties rather than a collection of lines.
  Change one element, like a beam's size, and every plan, section, and
  schedule that depends on it updates automatically instead of needing to
  be redrawn by hand. Multiple disciplines can work inside the same
  centralized model at once through worksharing, so a structural model
  and an architectural model stay coordinated as the design develops
  rather than getting reconciled only when someone remembers to check.
keyFeatures:
  - Parametric 3D modeling, where changing one element automatically
    updates every drawing and schedule that depends on it
  - Shared, centralized models so multiple disciplines work inside the
    same live project instead of trading files back and forth
  - Automatic generation of floor plans, sections, and schedules directly
    from the 3D model
  - Support for architecture, structural, and MEP disciplines inside one
    modeling platform
commonUses:
  - A structural engineer resizes a beam in the model, and every plan,
    section, and schedule referencing that beam updates automatically
    instead of being redrawn by hand
  - A BIM/VDC Specialist exports a discipline's Revit model into
    Navisworks so it can be checked against other trades' models for
    clashes
