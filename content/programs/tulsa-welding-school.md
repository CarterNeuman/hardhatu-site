whatToExpect: >
  A hands-on diploma program covering core welding processes
  (stick, MIG, TIG, flux-core) and blueprint reading, with heavy
  booth time compared to many community college programs. The core
  Welding Technology program typically runs about seven to eight
  months; a longer Welding Specialist track that adds pipefitting
  instruction runs somewhat longer and costs more. Published tuition
  for the core program has run in the roughly $19,000-22,000 range
  depending on campus, with total program cost (including books,
  tools, and fees) somewhat higher — exact pricing is set per campus
  and changes over time, so check directly with the campus you're
  considering. Financial aid is available to those who qualify. This
  is a private for-profit school, not a union apprenticeship, so
  there's no wage paid during training.
